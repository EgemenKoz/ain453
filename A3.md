Tasks3.1 Task 1: Implementation of the A* AlgorithmBased on the map information provided above, write an independent A* search algorithm.Your algorithm must find the lowest-cost path from the start node ($N_0$) to the target node ($N_{15}$).The algorithm must be implemented from scratch. Use of ready-made path planning libraries is not allowed.Implement Euclidean Distance or Manhattan Distance using $(x, y)$ coordinates as the heuristic function. No other heuristics are allowed.The algorithm must explicitly maintain OPEN and CLOSED lists.Each node must calculate and store $g(n)$, $h(n)$, and $f(n) = g(n) + h(n)$ values.In case of a tie in $f(n)$ values, the node with the lower $h(n)$ value should be selected.The final path must be reconstructed using parent tracking.Your code should output:The calculated path as a sequence (e.g., $N_0 \rightarrow N_1 \rightarrow \dots$)The total path cost.3.2 Task 2: Localization via Camera and ARTagsThe robot must use ARTags to determine its position on the global map.Detect ARTags in the environment using the robot's onboard camera (e.g., apriltag_ros).The robot must determine its current node based solely on the detected ARTag ID.A node is considered reached only if:The relevant ARTag is detected, andThe robot is within a predefined proximity threshold (e.g., distance < 0.3 m).The robot must continuously use ARTag detections to update its pose. A one-time detection is not sufficient.Before moving, the robot should orient itself toward the next node using ARTag pose information.If an ARTag is lost, the robot must stop or slow down and attempt to find it again.Localization must rely only on ARTags. Odometry-only or pre-programmed movements without ARTag feedback are not allowed.3.3 Task 3: Autonomous Navigation ControllerDevelop an autonomous control loop that follows the generated A* path to guide the robot from $N_0$ to $N_{15}$.The robot must not be controlled manually under any circumstances (via keyboard, joystick, etc.).When the robot is at node $N_i$, it must detect the ARTag of the next node in the path, $N_{i+1}$, and generate the necessary $V$ (linear velocity) and $w$ (angular velocity) commands (cmd_vel) to move toward it.When the robot detects and reaches the final ARTag $N_{15}$, it must stop autonomously and print a "Goal Reached" message to the terminal.4.
